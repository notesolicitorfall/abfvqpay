# Файлы проекта

В этом документе описано назначение основных файлов и папок информационной системы интернет-провайдера.

| Файл или папка | Для чего нужен                                                                                                                                                                                                                                                                   |
|---|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `app.py` | Точка входа и слой работы с данными. Здесь описаны сущности ER-модели, структура и миграция таблиц SQLite, связи, создание базы и демонстрационные записи. Здесь же находятся регистрация сотрудников, сохранение хешей паролей и проверка логина. При запуске файл передаёт управление графическому интерфейсу из `desktop.py`. |
| `desktop.py` | Графическая часть приложения. Создаёт формы входа и регистрации, главное окно, меню разделов, сводную панель и таблицы. Реализует фильтрацию данных по текущему сотруднику, поиск и CRUD-формы, диаграмму заключённых договоров за неделю, месяц и год, отображение автора договора и сообщения об ошибках. |
| `internet_provider.db` | Файл базы SQLite с аккаунтами сотрудников и их раздельными данными: клиентами, договорами, тарифами, адресами, оборудованием, IP-адресами, платежами и обращениями. Создаётся автоматически и сохраняет изменения после закрытия программы. Это данные, а не исходный код. |
| `.venv/` | Виртуальное окружение Python для проекта. Хранит используемый интерпретатор и установленные для него компоненты, чтобы запуск проекта не зависел от настроек других Python-проектов.                                                                                             |
| `README.md` | Краткая инструкция по запуску и общая информация о проекте. Содержит ссылки на подробные документы.                                                                                                                                                                              |
| `FILES_OVERVIEW.md` | Этот документ: объясняет, что делает каждый основной файл и для чего он нужен.                                                                                                                                                                                                   |
| `HOW_IT_WORKS.md` | Описание запуска приложения, взаимодействия графического интерфейса с базой и основных операций пользователя.                                                                                                                                                                    |

Python также может автоматически создавать папку `__pycache__/` с кэшированными байткод-файлами. Она не содержит пользовательские данные и не нужна для ручного редактирования.
