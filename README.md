# ИС интернет-провайдера

Настольная информационная система на Python с графическим интерфейсом Tkinter и базой данных SQLite. Приложение запускается отдельным окном и не требует браузера, веб-сервера или сторонних библиотек.

## Запуск

В PyCharm откройте `app.py` и нажмите **Run**. Или запустите из папки проекта:

```powershell
.\.venv\Scripts\python.exe app.py
```

Для запуска нужен Python 3 с Tkinter. При первом запуске рядом с приложением создаётся база `internet_provider.db` и заполняется демонстрационными данными. Первый зарегистрированный сотрудник получает существующие записи, последующие аккаунты работают со своими данными. Для чистого старта закройте приложение и удалите файл базы — это также удалит аккаунты и все сохранённые записи.

## Возможности

- Сводная панель с числом клиентов и активных договоров, оплатами за месяц и открытыми заявками.
- Таблицы клиентов, договоров, тарифов, адресов, оборудования, IP-адресов, платежей и заявок.
- Поиск, создание, редактирование и удаление записей через графический интерфейс.
- Связанные клиенты, тарифы, договоры и адреса выбираются из существующих записей.
- Регистрация и вход сотрудников по логину и паролю; у каждого сотрудника отдельные клиенты, договоры и остальные записи.
- Диаграмма количества заключённых сотрудником договоров за неделю, месяц и год.
- В договоре сохраняется сотрудник, который его заключил.
- SQLite обеспечивает хранение данных, уникальность ключевых идентификаторов и целостность связей.
